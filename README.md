# Supermarket Sales Analysis - Project 1

My first Data Science project using Python.

### Dataset
1000 Sales, 12 Columns
Source: Kaggle Supermarket Sales

### Key Findings
- Top City: New York (344 Sales)
- Top Product: Fruits (209 Sales)
- Average Price: $118.58
- Branch A (670) is 2x better than Branch B (330)
- Highest Sale: $433.99

Python, Pandas, Matplotlib, Google Colab, GitHub
